## Status conventions
**Agreed direction** records explicit founder decisions. **Proposed** requires review. **Verified** requires evidence with scope. **Open** is unresolved. Publication of a proposal is not approval to build or purchase it.

This initial documentation baseline was prepared on 2026-09-08 from the founder's planning conversation and supplied incident report/source excerpts. No product implementation or production deployment is implied.

## Information handling
No customer records, credentials, private keys, backups, or raw production logs belong here. Keep company knowledge durable, but operational secrets in a separate approved secret store. This repository is not a backup destination.
