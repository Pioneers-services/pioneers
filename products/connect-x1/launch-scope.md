# Launch scope
Status: Proposed sequencing; not a release commitment

## Foundation demonstration
Company setup → invite user → configure a workflow with Carminta X1 → create enquiry → detect and resolve an Action Center finding.

## Operational pilot candidates
- Companies, branches, users, record/action permissions.
- Customers, leads/enquiries, industry pricing, quotations, revisions, approvals.
- Payment recording and controlled order conversion.
- Design, drawings, production, measurements, handover.
- Scanning, notifications, role-specific dashboards.
- Carminta X1 configuration preview/approval/execution.

## Requested roadmap modules
Purchasing, suppliers, expenses, inventory consumption and actual project costing; advanced accounting; HR and country-specific payroll; maintenance/warranty; customer portal; integrations.

Prioritize costing and purchasing to complete pilot financial visibility. Full double-entry accounting and payroll require separate domain review and acceptance criteria. Final module order awaits Shaheen's review.

## Configuration vs development
Enable/configure existing capabilities through validated tools. A new module or changed core behavior becomes a Pioneers engineering request: develop → test → review → release. Do not generate customer-specific production code from chat.
